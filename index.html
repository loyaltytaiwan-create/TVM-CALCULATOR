現值計算 Present Value

已知未來的一筆金額，回推它在今天值多少錢。

現值 Present Value --
實際年利率 Effective Annual Rate (EAR) --
公式：PV = FV ÷ (1 + r/m)^(m·n)，連續複利 PV = FV · e^(-r·n)
現值＝未來值依名目年利率與複利頻率折現回今天的金額。
Present Value = the Future Value discounted to today at nominal rate r compounded m times per year.

終值計算 Future Value

已知現在的一筆金額，推算未來會累積成多少錢。

終值 Future Value --
實際年利率 Effective Annual Rate (EAR) --
公式：FV = PV · (1 + r/m)^(m·n)，連續複利 FV = PV · e^(r·n)
終值＝現值依名目年利率與複利頻率複利成長後的金額；EAR = (1+r/m)^m − 1。
Future Value = the Present Value compounded at nominal rate r, m times per year over n years.

年金計算 Annuity

每期支付（或收取）固定金額，計算其現值與終值。

年金現值 Present Value of Annuity --
年金終值 Future Value of Annuity --
公式：PVA = PMT × [1-(1+r)^-n] / r，FVA = PMT × [(1+r)^n-1] / r
年金現值／終值＝每期固定金額依年金因子折現或累積的總和（期初年金再乘以 (1+r)）。
Annuity value = the level payment discounted or compounded across n periods (Annuity Due multiplies by (1+r)).

永續年金與成長型年金 Perpetuity & Growing Annuity

現金流永久持續，或每期以固定成長率遞增時的現值。

現值 Present Value --

折現率必須大於成長率（r > g），否則現值發散為無限大（Discount rate must exceed growth rate）。

公式： 永續 PV = PMT / r； 成長永續 PV = PMT / (r − g)； 成長年金 PV = PMT/(r−g) · [1 − ((1+g)/(1+r))^n]
永續年金＝現金流永久持續的現值；加入成長率後，折現率必須大於成長率才會收斂。
A perpetuity pays forever; with growth, the present value converges only when the discount rate exceeds the growth rate.

貸款攤還表 Loan Amortization Schedule

等額本息攤還，逐期拆分利息與本金。

每期還款金額 Payment per Period --
總利息 Total Interest --
總還款金額 Total Paid --
總期數 Total Periods --
期數 期初餘額 Opening 還款額 Payment 利息 Interest 本金 Principal 期末餘額 Closing
公式：PMT = P · i / [1 − (1+i)^-N]，其中 i = 年利率/m、N = 年限×m
每期還款固定，其中利息＝期初餘額×期利率，其餘部分償還本金；隨期數增加，利息占比逐漸下降。
Each level payment covers interest on the opening balance first; the remainder reduces principal, so the interest share falls over time.

淨現值計算 Net Present Value

輸入折現率與各期現金流（第 0 期通常為投入成本，填負數）。

淨現值 Net Present Value --
公式：NPV = Σ CFt ÷ (1+r)^t，t = 0..n
淨現值＝將各期現金流折現到今天後加總；大於 0 代表這項投資划算。
Net Present Value = the sum of all cash flows discounted to today; a positive NPV indicates a worthwhile investment.

敏感度分析 Sensitivity Analysis

折現率變動時，NPV 如何隨之改變。曲線與零線的交點即為 IRR。

說明：逐一代入不同折現率重算 NPV，可看出這項投資對利率變化的敏感程度。
Recomputing NPV across a range of discount rates shows how sensitive the project is to rate changes; the zero crossing is the IRR.

內部報酬率計算 Internal Rate of Return

沿用與 NPV 相同的現金流序列，反推使 NPV 為 0 的報酬率。

內部報酬率 Internal Rate of Return --

無法求解：現金流需至少出現一次正負號變化（Cannot solve: cash flows need at least one sign change）。

公式：0 = Σ CFt ÷ (1+IRR)^t，以疊代法求解
內部報酬率＝使淨現值恰好等於零的折現率，數值越高代表投資報酬率越好。
Internal Rate of Return = the discount rate that makes NPV equal to zero, solved iteratively (Newton-Raphson).
